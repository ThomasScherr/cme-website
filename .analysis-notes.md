# SubPageHero Video Feature Analysis

## Current State
- SubPageHero already supports heroVideo prop with HeroVideo interface
- Three media variants: diamond, rectangular, floating - all support video
- The component itself is already video-ready

## What's Needed
1. CMS content fields for hero video URLs (per page)
2. Admin UI to upload videos and set them as hero media
3. SubPages need to read video URLs from CMS and pass to SubPageHero
