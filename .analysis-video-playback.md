# Video Playback Mode Analysis

## Current State
- SubPageHero has 3 media components: DiamondMedia, RectangularMedia, FloatingMedia
- All 3 have `autoPlay loop muted playsInline` hardcoded on `<video>` elements
- HeroVideo interface: { webm?, mp4?, poster? }
- SubPageHeroProps has `heroVideo?: HeroVideo`

## Plan
1. Add `videoPlayback?: 'loop' | 'once'` to HeroVideo interface (default: 'loop')
2. All 3 media components read this prop and conditionally set `loop`
3. For 'once' mode: video plays once on load, then shows the last frame (or poster)
4. CMS: add `heroVideoPlayback` field (type: text, default: 'loop') to all pages in contentDefinitions
5. SubPageTemplate reads `vid('hero.heroVideoPlayback')` or `t('hero.heroVideoPlayback')` and passes it

## Files to modify
- SubPageHero.tsx: HeroVideo interface + 3 media components
- SubPageTemplate.tsx: read CMS field, pass to SubPageHero
- contentDefinitions.ts: add heroVideoPlayback field to all pages
